# Vision

Instrument Flow Studio bertujuan menjadi platform visual untuk pembelajaran, perancangan, dan simulasi sistem instrumentasi dan embedded system.

Fokus utama:

1. Mempermudah pembelajaran instrumentasi.
2. Mengurangi kebutuhan hardware fisik untuk belajar.
3. Memberikan validasi koneksi secara realtime.
4. Menyediakan simulator yang mendekati kondisi nyata.
5. Menjadi platform open-source yang dapat dikembangkan komunitas.

Prinsip utama:

* Visual First
* Hardware Aware
* Beginner Friendly
* Extensible
* Open Source
