# MVP v0.1

Tujuan:
Membuat wiring editor sederhana untuk instrumentasi.

User dapat:
- Drag component
- Melihat pin
- Hover pin untuk melihat informasi
- Menghubungkan pin
- Menghapus koneksi
- Save project
- Load project

Component:
- ESP32
- Arduino Uno
- MQ2
- DHT22
- Relay
- LED

Belum ada:
- Simulator
- IDE
- Arduino compiler
- STM32
- PLC
