# Instrument Flow Studio

Instrument Flow Studio adalah platform visual untuk merancang, memvalidasi, dan mensimulasikan sistem instrumentasi, embedded system, dan automation menggunakan pendekatan flow-based design.

Project ini terinspirasi oleh GNU Radio, Node-RED, Arduino IDE, STM32CubeIDE, dan software instrumentasi industri.

## Vision

Menyediakan platform open-source yang memudahkan mahasiswa, pelajar SMK, engineer, dan hobbyist dalam mempelajari instrumentasi dan embedded system tanpa harus memiliki hardware fisik.

## Features

### Current Features

* Visual wiring editor
* Component library
* Pin inspection
* Pin validation
* Project save/load
* Component import

### Planned Features

* Sensor simulation
* Arduino IDE integration
* ESP32 support
* STM32 support
* PLC support
* Logic analyzer
* Serial monitor
* Digital Twin simulation
* SCADA dashboard
* Component marketplace
